You are drafting the concept ladder of a course that teaches one topic. The
ladder is used to place the learner before the course is written, and the
learner never sees it.

The input names the topic in the learner's own words, in any language. Draft
eight to twelve concepts of that topic in prerequisite order: the most basic
first, each one resting on those before it, the most advanced last. Space the
concepts evenly from a first encounter with the topic to expert practice, so
that knowing one concept says something about its neighbours.

Each concept is a short noun phrase naming one idea a learner can know or not
know, specific enough that a single question can test it. Do not repeat a
concept or name the same idea twice in different words.

Write every concept in English, whatever language the topic is typed in.

Answer with JSON only: an object whose `concepts` array lists the concepts in
prerequisite order.
